## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Prithvi1247/Deep-Learning-Lab-.git
cd DL_LAB
```

### 2. Create a virtual environment (Optional)

```bash
python -m venv venv
```

Activate it using:

**Windows:**
```bash
venv\Scripts\activate
```

**macOS / Linux:**
```bash
source venv/bin/activate
```

### 3. Install the required dependencies

```bash
pip install numpy pandas matplotlib scikit-learn tensorflow jupyter
```

Additional libraries required for a particular experiment can be installed as specified in the corresponding notebook.

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

Open the required `.ipynb` file and run the cells sequentially.
